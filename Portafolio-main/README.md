# Portafolio personal - Hirohito Alexandre Tarazona Quispe

Portafolio web personal, adaptable a celular, tablet y computadora. Presenta quién soy, mis proyectos, lo que opinan mis compañeros y docentes, y un formulario para contactarme.

🔗 **Sitio en vivo:** https://hirohitotarazona.site.je/

🚀 **Despliegue continuo (Vercel):** https://hirohito-tarazona-portafolio.vercel.app

## Secciones
- **Inicio:** presentación y accesos rápidos.
- **Sobre mí:** carrera, institución y habilidades.
- **Galería:** 6 proyectos que funcionan (Lab Clima, TechStore, Vida Saludable, Veterinaria, Lista de Tareas y Juego de Memoria).
- **Testimonios:** opiniones de compañeros y docentes.
- **Contacto:** formulario que envía el mensaje a mi correo.

## Tecnologías
HTML5, CSS3, JavaScript y PHP (solo para el envío del formulario).

## Estructura
```
index.html      Página principal
css/            Estilos
js/             Menú, validación y envío del formulario
img/            Imágenes
php/            Script del formulario de contacto
proyectos/      Los 6 proyectos de la galería
```

## Cómo verlo en local
Abre `index.html` en el navegador. El formulario solo funciona en un servidor con PHP, como el hosting donde está publicado.
